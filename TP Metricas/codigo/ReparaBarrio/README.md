# ReparaBarrio — APO1 Programación Concurrente

Proyecto académico desarrollado mediante Codex (IA) y metodología
Spec-Driven Development (SDD).

## Tecnología
- Java 21
- Maven
- H2 embebida
- JUnit
- Programación concurrente y sincronización

## Estado del desarrollo
- H1, H2 y H3: implementados y validados previamente.
- H4: implementado parcialmente, con limitaciones conocidas en
  recuperación de sesiones, asignaciones y transacciones.
- Recorrido académico nominal: validación pendiente o en curso.
- H5 y H6: pendientes de implementación en esta versión.

## Ejecución y pruebas
Desde esta carpeta y con Java 21/Maven configurados:

mvn test

La suite completa puede presentar fallos H4 documentados.
No se declara aprobada la recuperación avanzada.

## Alcance
Prototipo académico para analizar el desarrollo mediante vibe coding,
la metodología SDD y los conceptos de Programación Concurrente.

No apto para uso operativo en producción.

## Autoría y proceso
Código generado mediante Codex con especificación, decisiones,
supervisión, pruebas y validación humana.
