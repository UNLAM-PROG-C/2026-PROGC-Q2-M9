# ReparaBarrio — APO1 | Grupo M9

**Programación Concurrente — UNLaM — 2026**

## Descripción del proyecto

ReparaBarrio es una aplicación de escritorio desarrollada en Java 21 para la gestión de órdenes de reparación de un taller, con énfasis en la programación concurrente, la coordinación de recursos compartidos y la sincronización de operaciones.

El sistema contempla dos modalidades: una operativa, que permite administrar órdenes y recursos del taller, y otra de simulación, que ejecuta reparaciones ficticias mediante tareas concurrentes para observar y evaluar su comportamiento.

El proyecto fue desarrollado con asistencia de **Codex CLI**, siguiendo una metodología de **desarrollo guiado por especificaciones (Spec-Driven Development, SDD)**, que comprendió etapas de especificación, planificación, diseño, implementación, pruebas y refinamientos.
